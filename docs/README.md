- `cd backend && npm test`: unit tests plus an optional PostgreSQL integration test. Set `VIDSCRIBE_TEST_DATABASE_URL` to a disposable empty database with `test` in its name to enable the integration case.
- A dedicated disposable PostgreSQL target is available via the repository-root `docker-compose.test.yml`; its start, test, and reset commands are in the root README.
- `npm run test:e2e` runs the Playwright Chromium suite against that isolated database. It covers the source evidence workspace, transcript search/pagination, exports, and legacy transcript refresh states. See [the automated browser-suite decision](decisions/automated-browser-suite.md) and the [transcript service guide](services/transcript-service.md).
- [GitHub Actions validation](decisions/ci-validation-workflow.md) runs the build, frontend lint, PostgreSQL integration tests, and provider-free Playwright suite for every pull request. Browser failure artifacts are retained for 14 days.
